# Acton fixture provenance

Counter.json, NftItem.json, JettonWallet.json and JettonMinter.json contain code produced from Acton 1.0.0 built-in counter, nft and jetton templates (Acton commit prefix 3a4f0dc). They were generated by `acton new --template <template>` followed by `acton build` on 2026-10-08. The template projects' original tests passed: counter 8, nft 21, jetton 48.

Acton upstream: https://github.com/ton-blockchain/acton

The archived code is tested with synthetic storage and messages in ../acton-probes.mjs. These fixtures contain no wallet credentials, private keys or live account data. The template's MIT license is included as LICENSE. To regenerate equivalent fixtures, use the same Acton version and its built-in templates; compiler/template version changes may change the code hashes.
