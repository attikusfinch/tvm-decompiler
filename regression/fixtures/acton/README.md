# Acton fixture provenance

The eight JSON fixtures contain code produced from all Acton 1.0.0 built-in templates (Acton commit prefix 3a4f0dc): empty (Empty), counter (Counter), nft (NftCollection and NftItem), jetton (JettonWallet and JettonMinter), and w5-extension (SimpleExtension and WalletV5). They were generated by `acton new --template <template>` followed by `acton build` on 2026-10-08. The template projects' original tests passed: empty 4, counter 8, nft 21, jetton 48, w5-extension 4; 85 total. The matching project sources, generated JettonWallet dependency, configurations and licenses are archived in ../acton-sources.

Acton upstream: https://github.com/ton-blockchain/acton

The archived code is tested with synthetic storage and messages in ../acton-probes.mjs. These fixtures contain no wallet credentials, private keys or live account data. The template's MIT license is included as LICENSE. To regenerate equivalent fixtures, use the same Acton version and its built-in templates; compiler/template version changes may change the code hashes.
